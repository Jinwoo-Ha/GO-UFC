
            

# 🥊 UFC Platform





## 📙 Project Description
This project is a UFC (Ultimate Fighting Championship) platform where users can freely share their thoughts, engage with the UFC community, and access the latest UFC content, including videos, fighter profiles, and upcoming events.





## 🌟 Key Features
- 📹 **Video Sharing**: Users can upload and share their favorite UFC videos.
- 🗣️ **Community Interaction**: Features a community section where users can create posts, reply to others, and engage in discussions.
- 🥊 **Fighter Profiles**: Detailed profiles of UFC fighters, including statistics and match history.
- 📅 **Upcoming Events**: Stay updated with the latest and upcoming UFC events.
- 🔍 **Search Functionality**: A robust search feature for searching fighters and videos.
- 💬 **Real-time Chat Room**: Users can chat with each other in real-time.





## 🔧 Installation Guide
1. Clone the repository:
   ```bash
   git clone {github repository url}
   ```
2. Change to the cloned directory:
   ```bash
   cd {cloned directory}
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Perform database migrations:
   ```bash
   python manage.py makemigrations
   python manage.py migrate
   ```
5. Finally, run the Django server:
   ```bash
   python manage.py runserver
   ```
